# Code of Conduct

## Our Standard

Contributors are expected to keep discussion respectful, constructive, and focused on improving CSPR AgentPay Guard.

Examples of welcome behavior:

- Be clear and considerate in issues, pull requests, and reviews.
- Give technical feedback without personal attacks.
- Respect that this project is a hackathon prototype with explicit real-vs-mock boundaries.

Unacceptable behavior includes harassment, discriminatory language, threats, personal attacks, or publishing private information such as keys, wallet files, secrets, or credentials.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation for behavior that violates this code. Security-sensitive concerns should be reported using `SECURITY.md`.
